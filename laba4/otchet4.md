# Отчет
## Задание 1
### Условие:
Замыкание, отбирающее только уникальные значения из переданных.
Примените декоратор к замыканию.
### Описание проделанной работы:
Реализована функция unique, которая возвращает только новые уникальные элементы при каждом вызове. Добавлен декоратор my_decorator для вывода сообщений о начале и завершении работы функции. Замыкание позволяет сохранять историю переданных элементов между вызовами.

## Задание 2
### Условие:
Декоратор, который будет ограничивать количество вызовов функций.
### Описание проделанной работы:
Реализован декоратор limit_calls, ограничивающий количество вызовов функции. При превышении лимита выводится сообщение об ошибке и возвращается None. В примере функция say_hello может быть вызвана не более трёх раз.

## Задание 1 (medium)
### Условие:
Создайте декоратор с опциональным параметром. Подумайте о поддержке рекурсивных функций.
### Описание проделанной работы:
Доработан декоратор limit_calls: теперь он принимает необязательный аргумент n. Если n не указан, ограничение не применяется. Добавлена функция recursive_sum для демонстрации работы рекурсии. В примере показаны два варианта использования: с ограничением в 3 вызова и без ограничений.
