# Отчет
## Вариант 1
### Условие:
Реализуйте приложение с GUI (приложения-игры допускается делать с использованием TUI-пакетов) по своему варианту. Можно изменить задание на собственную тему, согласовав с преподавателем. Требования:
приложение должно быть написано с применением ОО парадигмы
исключительные ситуации должны обрабатываться с использованием собственных исключений
GUI/TUI фреймворки не должны повторяться в группе.
### Задание: 
Система учета задач (ToDo)

### Описание проделанной работы:
Создано ToDo-приложение из 3 модулей:
1. exceptions.py — собственные исключения (EmptyTaskError, TaskNotFoundError)
2. database.py — класс Database для работы с SQLite (добавление, удаление, выполнение задач)
3. models.py — класс Task (модель задачи с id, названием и статусом)

main.py — главный модуль с GUI на Tkinter:
Поля для ввода задач
Список всех задач
Кнопки: Добавить, Выполнить, Удалить
Данные сохраняются в todo.db

Итог: Реализован функционал добавления, удаления и отметки выполнения задач с сохранением в БД и обработкой ошибок через собственные исключения.
